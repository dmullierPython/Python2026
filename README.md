
# Python2026 Duncan's Repository Summary

* **[Session 4 Loops](https://github.com/dmullierPython/Python2026/tree/main/Session%204%20Loops)** 
  * Covers `for` loops (`range()` counting up, down, and stepping, plus iterating over strings), `while` loops (counting and input validation), and `do..while`-style patterns using `while True` and `break`.

* **[Session 5 Selection](https://github.com/dmullierPython/Python2026/tree/main/Session%205%20Selection)** 
  * Demonstrates conditional branching (`if`, `elif`, `else`), compound boolean conditions (`or`), range validation (1–10), and EAFP ("easier to ask for forgiveness than permission") input validation using `try` / `except ValueError`.

* **[Session 6 Functions](https://github.com/dmullierPython/Python2026/tree/main/Session%206%20Functions)** — [session6.md](https://github.com/dmullierPython/Python2026/blob/main/Session%206%20Functions/session6.md)
  * Introduces grouping reusable code into functions, covering built-in functions (`len()`, `sort()`, `print()`), importing from the Python standard library, writing custom functions with parameters, return values, and local variable scope, and importing custom modules (`__name__`).

* **[Session 7 Lists and Project Example](https://github.com/dmullierPython/Python2026/tree/main/Session%207%20Lists%20and%20Project%20Example)** — [session7.md](https://github.com/dmullierPython/Python2026/blob/main/Session%207%20Lists%20and%20Project%20Example/session7.md)
  * Walks through an incremental football results and league table application (`V1`–`V7` / 9 Git commits), progressing from basic list printing and validation to score parsing, error handling, file reading, league table calculation, and passing `matches.txt` via command-line arguments.

* **[Session 8 Packages and Dependencies](https://github.com/dmullierPython/Python2026/tree/main/Session%208%20Packages%20and%20Dependencies)** — [session8.md](https://github.com/dmullierPython/Python2026/blob/main/Session%208%20Packages%20and%20Dependencies/session8.md)
  * Explains creating, activating, and deactivating isolated `.venv` virtual environments, installing third-party PyPI packages (`requests`) via `pip`, fetching Leeds weather data from a public API (`forecast.py`), and exporting/recreating dependencies with `requirements.txt` (plus a note on `uv`).
